# Projeto Social — Associação Deus é Fiel

Projeto de desenvolvimento de soluções digitais para a Associação Deus é Fiel, localizada em Paulista–PE, com o objetivo de fortalecer sua presença digital e apoiar a organização de seus processos internos.

## 📌 Sobre o projeto

O projeto é composto por duas aplicações complementares:

### 🌐 1. Site Institucional
Plataforma pública para apresentar a história da associação, seus serviços gratuitos, projetos sociais, cursos e oportunidades de voluntariado.

🔗 **Acesse o site:** https://deusfiel-mwbwyehr.manus.space

### ⚙️ 2. CRM — Sistema de Gestão
Sistema web desenvolvido para apoiar a gestão interna da instituição, reunindo funcionalidades como:

- Cadastro e gerenciamento de beneficiários.
- Agendamento e organização de atendimentos.
- Gestão de profissionais.
- Registro e acompanhamento de atendimentos.
- Painéis gerenciais e relatórios.
- Gestão de oficinas, cursos e participação.

O sistema conta com controle de acesso por perfil e recursos de acessibilidade, buscando oferecer uma experiência mais organizada e inclusiva.

## 🛠️ Tecnologias

**Front-end:** React, TypeScript, Vite e Tailwind CSS.

**Back-end:** Node.js, Express e tRPC.

**Banco de dados:** MySQL/TiDB, com Drizzle ORM.

## 🎯 Objetivo

Aplicar conhecimentos de desenvolvimento de software na construção de soluções que atendam a necessidades reais, contribuindo para a organização dos processos e para a transformação digital de uma iniciativa social.

## ♿ Acessibilidade e qualidade

Foram considerados recursos de acessibilidade baseados nas diretrizes WCAG 2.2, além de testes automatizados e validações técnicas durante o desenvolvimento.

## 📂 Organização do repositório

- `site-institucional/` — código do site público.
- `crm/` — código do sistema de gestão.

## 🤝 Impacto social

Este projeto conecta tecnologia e responsabilidade social, buscando apoiar o trabalho da associação e facilitar a organização de suas atividades.
